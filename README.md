# One-Star Review of Something Essential

A deadpan one-star review of sleep, the everyday essential nobody can opt out of. `main.ts` writes the line to `entry.txt`, enforcing the gates — non-empty, at most 160 characters, exactly one line and exactly one sentence ending in a single period — then reads the file back and verifies the bytes match.

> "Sleep takes a third of my life, asks for eight hours a night, and still has the nerve to leave me tired."

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/u-0xb3e689-review-out node main.ts
```
